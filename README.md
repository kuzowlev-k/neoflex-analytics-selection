## О репозитории

Репозиторий содержит решения трёх заданий отборочного этапа по направлению Analytics:

1. **Задание 1** — описание функциональных и нефункциональных требований.
2. **Задание 2** — модель бизнес-процесса отбора студентов (BPMN-диаграмма + текстовое описание).
3. **Задание 3** — проектирование БД Учебного центра (концептуальная и логическая модели) и написание SQL-запросов.

Все задания оформлены в Markdown, диаграммы — в открытых форматах `.bpmn` и `.drawio`.

## Как открыть файлы

### Файлы `.bpmn`

Формат **BPMN 2.0** — стандарт для описания бизнес-процессов. Открывается в браузере без установки ПО.

**Способ 1 — онлайн (рекомендуется):**

1. Скачай файл [`otbor_studenta.bpmn`](task_2_business_process/otbor_studenta.bpmn):
   - Открой ссылку на GitHub
   - Нажми кнопку **Download raw file** (иконка загрузки в правом верхнем углу) или **Raw** → сохрани файл
2. Перейди на [https://demo.bpmn.io](https://demo.bpmn.io)
3. Нажми **Open File** (или перетащи скачанный файл прямо в окно браузера)
4. Диаграмма откроется, можно посмотреть, поредактировать и экспортировать в PNG/SVG

---

### Файлы `.drawio`

Формат **draw.io (diagrams.net)** — открытый формат для диаграмм и схем.

**Способ 1 — онлайн:**

1. Скачай файл (например, [`conceptual_er.drawio`](task_3_db_design_sql/conceptual_er.drawio)):
   - Нажми кнопку **Download raw file** (иконка загрузки в правом верхнем углу) или **Raw** → сохрани файл
2. Перейди на [https://app.diagrams.net](https://app.diagrams.net)
3. **File → Open From → Device** → выбери скачанный файл
4. Можно смотреть, редактировать, экспортировать в PNG/SVG/PDF
